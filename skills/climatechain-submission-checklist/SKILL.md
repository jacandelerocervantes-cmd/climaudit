# ClimateChain submission checklist

Read `RULES.md`. The official rules prevail; dates and prizes `[VERIFY]` against Devpost.

## Backward plan
| Date | Must be ready |
|---|---|
| Oct 25, 8:00 AM CST | Devpost closes (organizer page says 11:59 PM UTC; use the earlier time) |
| Oct 24, 6:00 PM CST | Target submission time |
| Oct 24 | Final video, README, Devpost description |
| Oct 22–23 | Full flow on testnet and deployed demo |
| Oct 20–21 | Verification agent and policy |
| Oct 18–19 | Token, audit topic and deterministic verifier |
| Oct 16–17 | Accounts, public repository and environment |

## Official requirements
- [ ] Declared track and how it answers the challenge
- [ ] Description: problem, solution, users, scalability, adoption
- [ ] Video of 3 minutes or less showing the project in use
- [ ] Public repository with code and documentation
- [ ] Working prototype or demo (Hedera testnet deployment is acceptable)
- [ ] Architecture diagram and technical specification (organizer requirement)
- [ ] Security and data integrity assessment document (organizer requirement)
- [ ] Recommended, not required: at least 45 seconds of the video showing live Hedera testnet transaction ids and Guardian outputs
- [ ] Impact material the organizer lists: problem statement and solution overview (max 2 pages), climate impact assessment, adoption strategy, scalability roadmap `[VERIFY which are mandatory]`
- [ ] Eligibility confirmed (age of majority, student/individual status, non-excluded country, team size, one entry per person) `[VERIFY: the pasted Devpost text and the organizer page differ]`

## Quality
- [ ] Data labeled measured / modeled / synthetic
- [ ] Video figures reproducible from saved outputs
- [ ] AI use declared
- [ ] Keys and `.env` kept out of the repository
- [ ] Self-assessment with `climatechain-judge-simulator`

## Fails if…
- It is submitted after Devpost closes (Oct 25, 8:00 AM CST); the internal target is Oct 24, 6:00 PM CST.
- The video exceeds 3 minutes or does not show the project working.
- The agent submits on its own: the human presses "Submit".

## For your review
Eligibility, final version of the video, acceptance of terms (only you).
